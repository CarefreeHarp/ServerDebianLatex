\section{Estrategias de búsqueda bibliográfica}

\subsection{Motores de búsqueda utilizados}

\subsection{Palabras clave}

Las búsquedas se realizaron en español e inglés utilizando las siguientes palabras clave:

\begin{enumerate}
    \item Incendios forestales.
    \item \textit{Wildland fire simulation}.
    \item FARSITE.
    \item WFDS.
    \item \textit{Wildland-urban interface}.
    \item \textit{Fire spread prediction}.
    \item GIS.
    \item \textit{High-performance computing}.
    \item \textit{Scenario retrieval}.
    \item \textit{Multiscale modeling}.
\end{enumerate}

\subsection{Temas abarcados en la investigación}

\begin{enumerate}
    \item Modelado y propagación de incendios.
    \item FARSITE.
    \item Modelo de Rothermel.
    \item FDS/WFDS.
    \item Incendios en la interfaz urbano-forestal (WUI).
    \item Computación de alto rendimiento (HPC) y paralelización de simulaciones.
    \item Modelos multiescala.
    \item Sistemas de Información Geográfica (SIG).
    \item Modelos \textit{surrogate}.
\end{enumerate}
