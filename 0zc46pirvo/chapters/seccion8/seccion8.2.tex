\subsection{Lenguajes y Herramientas [Pendientes: elegir tecnologías de aplicación y pruebas y proveedor de API; fijar versiones y verificar compilación, ejecución e integración de FDS y Smokeview; configurar repositorio y reglas de Git; confirmar acceso documental definitivo y recursos HPC]}\label{sec:spmp-8-2}
FDS es el software de simulación empleado para preparar los escenarios y Smokeview es el visualizador previsto para sus resultados. UML 2.5.1 comunica el diseño y Git conserva las versiones del código de la aplicación. Aldine centraliza la elaboración colaborativa de documentos LaTeX y la bibliografía~\cite{uml,servidor2026}.

El servidor documental es un computador ubicado en casa de Daniel; su documentación describe contenedores de aplicación, compilador y gateway Nginx, acceso mediante Tailscale, almacenamiento persistente, repositorios Git por proyecto y respaldo consolidado hacia GitHub. El esquema documental de conservación se presenta en la sección \ref{sec:spmp-12-3}; los ámbitos de infraestructura se describen en la sección \ref{sec:spmp-9-2-2}~\cite{servidor2026}.

El repositorio \url{https://github.com/ruddymell/wfds6} se conserva como antecedente técnico consultado sobre WFDS. El software que se configura y ejecuta en el proyecto se denomina FDS según la convención de la sección \ref{sec:spmp-6-1}. La compilación documental del PMP utiliza LuaLaTeX con Carlito y Caladea.
