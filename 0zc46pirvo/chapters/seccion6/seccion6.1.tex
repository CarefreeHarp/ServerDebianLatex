\subsection{Visión del Producto}\label{sec:spmp-6-1}
La herramienta de simulación empleada en el proyecto es \textit{Fire Dynamics Simulator} (FDS). Históricamente, \textit{Wildland-Urban Interface Fire Dynamics Simulator} (WFDS) surgió como una extensión de FDS para modelar incendios forestales y de interfaz urbano-forestal, cuyas capacidades fueron posteriormente integradas en FDS. En este documento, FDS designa el software utilizado, mientras que WFDS se emplea para hacer referencia específica a dichas capacidades de simulación en contextos forestales, sin implicar el uso de un simulador independiente~\cite{fdsnist,wfdsusfs}.

La aplicación ofrecerá al comandante o coordinador de la operación una forma de explorar posibles comportamientos del incendio mediante resultados de simulación preparados con anterioridad, de modo que pueda consultar y comprender información georreferenciada sin configurar directamente el modelo científico durante el incidente. La aplicación se concibe exclusivamente para escritorio y combina una biblioteca de escenarios FDS con una consulta en la que el comandante marca manualmente la ubicación o el perímetro observado del incendio. Las condiciones meteorológicas se obtendrán mediante una API; si el servicio no está disponible, el comandante podrá diligenciarlas manualmente. El diseño contempla seleccionar escenarios compatibles, agregar resultados desde el borde activo, excluir el interior identificado como quemado y presentar mediante Smokeview una animación georreferenciada que pueda actualizarse cuando existan nuevas observaciones. La biblioteca y la aplicación también podrán utilizarse como material de capacitación.

El cambio esperado es facilitar la interpretación de escenarios dentro de las condiciones representadas y comunicar sus límites de forma comprensible. Por ello, el producto apoyará el juicio del usuario y no emitirá decisiones operativas automáticas ni garantizará una predicción exacta. La evaluación del producto toma como base la evaluación con usuarios y la trazabilidad descritas en la sección \ref{sec:spmp-8-3}, y los fundamentos de calidad de la sección \ref{sec:spmp-12-5}. La corrección del software se distingue de la evidencia científica que respalda los resultados.
